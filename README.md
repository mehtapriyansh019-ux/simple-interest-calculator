# Simple Interest Calculator

## Description
A simple calculator to calculate the Simple Interest based on the Principal Amount, Rate of Interest, and Time.

## Formula

Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time

## Example

If:
- Principal = ₹10,000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (10000 × 5 × 2) / 100
                = ₹1,000

## Features
- Calculates simple interest
- Easy to use
- Simple and beginner-friendly
